# C · 方位 / Spatial Compass

空间方向优先的高保真设计探索。松针绿与暖沙色构成安静、留白充足的工作台；把传感器朝向示意作为主视觉，右侧直接核对三路读数，下方用紧凑的 30 秒趋势保留时间信息。它与 A 的浅色数据面板、B 的深色高密控制台在布局、密度、主视觉和阅读顺序上都有明显差别。

- `index.html`：1440 × 1000 桌面基准，390 px 手机响应式；手机采用单列自然滚动。
- `design-spec.json`：1440 × 1000 框坐标、尺寸、颜色、字体、文案、简单几何及折线；`elements` 为可编辑 Figma 重建使用的扁平列表。
- `assets/`：本地 Sora、Noto Sans SC、IBM Plex Mono 字体及 OFL 许可；无 CDN 依赖。

图示是静态的传感器朝向示意，距离刻度非等比，非地图、雷达扫描或 3D 重建。所有数值标为演示数据；三路状态与更新时间独立。激光默认按 mm 解读原始值 1284，显示 128.4 cm；前方超声波显示 46.2 cm，上方超声波超时。

连接、断开、演示、CSV 按钮仅显示本地预览反馈。三条曲线可分别显隐；原始单位切换只影响激光；串口诊断可展开。未调用 Web Serial、未连接硬件、未启动服务，未更改现有前端。

源内容只读核对自 `distance_mac_viewer/index.html`、`styles.css`、`app.js`、`README.md`。设计文件尚待独立 verifier 做视觉与交互检查。
