# B / Control Room

Purpose: observe three asynchronous distance channels through one Pico USB.

Tone: precise, calm, professional. Graphite surfaces, amber laser trace, ice-cyan front trace, and a neutral dashed upper trace reserve color for channel identity and status. The dominant oscillograph and fixed session rail give this concept a distinct instrument-console hierarchy.

Open `index.html` directly. It uses bundled fonts and no external requests. Buttons demonstrate local UI feedback only; no hardware or application integration exists. `design-spec.json` contains absolute 1440×1000 geometry, text styles, native rectangles, and editable scientific trace paths for Figma recreation. The 390px layout stacks telemetry above the chart.

All values and protocol lines are clearly labelled demonstration data. TFmini raw unit is mm, the TF parsing interval is not presented as a real sampling interval, and the three channels retain independent status and age.
