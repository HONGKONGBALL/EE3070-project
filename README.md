# EE3070 智能盲杖

> **2026-10-24 当前样品：单摄像头优先。** 独立入口与说明见
> [单摄像头样品](docs/camera-sample.md)。它使用现成 YOLO11n NCNN 权重，
> 不要求 Pico、双目标定、导航或焊接音响；HyperX USB 耳机可播放英语提示。
> 下文是原整机方案，坡度/麦克风等不自动成为本次样品要求。

EE3070 课程项目，4 人组。在一根普通折叠盲杖的上段装 Raspberry Pi 5 + Raspberry Pi Pico H，加上超声波、激光测距、IMU、摄像头、振动马达、蜂鸣器和语音提示，帮视障用户提前知道前方和头部高度的障碍、落差和不平路面，并在有手机热点时按高德步行路线播报转向。

- 预算硬顶 **¥1000**（不含已有和实验室借用的器材）。
- 本学期约剩 5 周（2026-10-06 确认）。期末演示日期未定，排期暂按 2026-11-08 估计。
- 续航验收：夜间工况实测 **≥ 2 h**。6 h 不是本学期目标。

> 方案以 2026-10-08 交接文档和当晚的补充决定为准：除下段 ToF 外其余功能本学期全部要做；主方案改用真北醒 TFmini-S，另加 MPU6050、三极领夹麦、5.5 V 1 F 超级电容。

## 1. 本学期范围

### 1.1 必做

| 功能 | 说明 |
|---|---|

| 行进中视觉里程计 | 单目 ORB 特征 + 本质矩阵估计航向变化，用来判断「停步对正后有没有转偏」。估计不可信时，不发左右指令。 |
| 不平地面分类 | **没有下段 ToF 也要做**，做法见 [1.3](#13-没有下段-tof-时不平分类怎么做)。 |
| 坡向提示 | 停步时用双目深度拟合地面平面，读出上坡 / 下坡 / 左右倾。 |
| 唯一输出仲裁 | 所有语音、振动只经一个仲裁器输出。**安全提示永远排在转向提示前面**，可以打断正在播的导航句。 |
| 三语提示音 | 普通话、粤语、英语三套，TTS **预先生成**，配置里选语言，运行时播本地文件。安全提示全部预录。 |
| 手机热点 + 高德步行导航 | Pi 连手机热点，调高德 Web 服务步行路径规划。手机网页（HTTPS）把定位传给 Pi。断网时导航退出，避障照常。 |
| 过街交接 | 路线里遇到过马路 / 人行横道 / 天桥 / 地下通道时，盲杖让用户停下、提示「前方过街」，由用户自己判断信号灯和车流，按键确认后才继续播路线。盲杖**不判断**能不能过。 |

| 视障用户测试 | 本学期要做。需要先走 CityU 伦理流程（流程本仓库未核实），测试只在封闭场地、有组员陪同。报告照实写。 |

### 1.2 本学期不做

| 不做 | 原因 |

**必须写进报告的限制**：本项目是「**用手机热点和高德验证导航流程**」，**不是**已经满足 PRD 的「杖自己独立联网」（U02），也没有杖上定位，位置来自手机。封闭场地只有几十米，手机定位常有几米误差，场地内小路不一定在高德路网里，所以在场地内按路线逐段转弯不可靠；演示时转向提示只在用户停步对正后发。

### 1.3 没有下段 ToF 时不平分类怎么做

原文档写的是「靠下段 ToF/IMU + 采集、打标签、训练」。下段 ToF 不做，不平分类改成下面三路，**不再需要新件**（MPU6050 已在 18 项清单里）：

1. **杖身 MPU6050 振动**：滑轮杖头在地面滚动时，杖身加速度的高频能量和频谱随路面变化。按步行窗口（约 1 s）算 RMS、峰值、过零率、频带能量，分「平整 / 粗糙（砖缝、碎石）/ 草地或软地」。先用阈值分类跑通，再采数据训练小模型（`cane/terrain.py` 里留了接口）。
2. **TFmini-S 斜向下测地面**：平地时测距稳定在由安装高度和倾角算出的期望值附近；突然变长 → 落差/下台阶，突然变短 → 上台阶/路缘/障碍；起伏方差大 → 不平。
3. **停步双目深度**：地面平面拟合的残差大 → 不平；平面法向 → 坡向。

做不到的部分要直说：**杖尖前 0.4 m 以内的小坑、小落差**原本靠下段 ToF 提前发现，现在只能在杖尖碰到后由 IMU 冲击感知（是事后，不是提前），报告里要写明。振动分类需要组员在 2–3 种路面上采数据和打标签，没有数据时只有阈值版本。

### 3.1 输出仲裁规则（`pi/cane/arbiter.py`）

优先级从高到低：`CRITICAL`（停止/掉坑/系统故障）> `SAFETY`（障碍、头部、落差）> `SYSTEM`（启动、电量、网络）> `NAV`（转向、过街、到达）> `INFO`。

- 同一时刻只有一个声音在播；更高优先级可以打断正在播的低优先级句子。
- 安全提示播完后有一段保持时间（默认 2 s），这段时间里不播导航句。
- 同一句在冷却时间内不重复。
- 朝向不确定（未停步对正，或视觉里程计判断已转偏 / 不可信）时，**丢弃左右指令**，只保留「请停下对正」。
- 诊断网页和任何网络接口都不能清除安全否决。

### 3.2 状态机（`pi/cane/state_machine.py`）

`BOOT → READY ⇄ WALKING ⇄ STOPPED(对正/扫描)`，导航中可进入 `CROSSING`（过街交接，等按键确认），任一状态在传感器或 Pico 超时时进入 `FAULT`，恢复后回 `READY`。测试模式是一个标志，诊断网页会显示。

### 3.3 Pico ↔ Pi 协议（`pico/protocol.py`）

USB CDC 串口，每行一条 JSON：

- Pico → Pi：`{"t":"d","f":123,"u":250,"g":180,"gs":900,"ms":12345}`（前/上仰超声 cm、TFmini cm 与信号强度，无效为 -1）；`{"t":"b","id":"ok","ev":"short"}`（按键）；`{"t":"p","vsys":4.95}`（电源）。
- Pi → Pico：`{"t":"h"}`（心跳）；`{"t":"v","p":"stop"}`（振动图案）；`{"t":"l","v":0.6}`（灯亮度）；`{"t":"z","p":"beep"}`（蜂鸣器）。

### 3.4 提前量（附录 B）

所需报警距离 = 步速 × (传感延迟 + 最长那条语言提示的时长 + 听懂 0.5 s) + 余量。三种语言同一句长短不同，按**最长**的算；超过上限就改短句子。`tools/check_lead_time.py` 会读生成好的音频时长逐句检查，落差/台阶的可见距离按 TFmini-S 的安装高度和下倾角算。

已发现的一条：TFmini-S 装在约 0.85 m 高、下倾 35° 时，光斑只在前方约 1.2 m；1 m/s、0.6 s 的提示就需要约 1.65 m，来不及。所以默认改成下倾 25°（光斑约 1.8 m 前，斜距约 2.0 m），振动和语音同时发出。实际角度要在杖上实测，掠射角变小后地面回波强度会下降，要看 TFmini-S 的信号强度是否还够。

## 5. 怎么运行

### 5.1 在电脑上先跑模拟（不需要硬件）

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[web,test]"
pytest                                   # 单元测试
python -m cane --sim --config config/config.example.toml
# 浏览器打开 http://127.0.0.1:8080/ 看诊断网页
```

`--sim` 用模拟 Pico（随机障碍）和打印代替播放，不调高德（除非设置了 `AMAP_KEY`）。

### 5.2 树莓派 5

```bash
sudo apt install -y python3-venv python3-opencv alsa-utils i2c-tools
sudo raspi-config nonint do_i2c 0        # 打开 I²C（MPU6050）
python3 -m venv --system-site-packages .venv && . .venv/bin/activate
pip install -e ".[web,pi]"

cp config/config.example.toml config/config.toml   # 按实际改，config.toml 不入库
export AMAP_KEY=你的高德Web服务Key                  # 不要写进仓库
export CANE_PHONE_TOKEN=随便一串长随机字符           # 手机定位页口令

aplay -l                                 # 找 USB 声卡编号，填到 audio.device
tools/make_cert.sh                       # 手机定位页要 HTTPS
python tools/calibrate_stereo.py capture   # 双目标定（摄像头装好后做一次）
python tools/calibrate_stereo.py solve
python -m cane --config config/config.toml
```

IMU、摄像头没接或没标定时，程序会记一条警告并在没有这部分功能的情况下继续跑（避障不受影响）。

开机自启：`sudo cp deploy/cane.service /etc/systemd/system/ && sudo systemctl enable --now cane`（先改里面的路径和环境文件）。

### 5.3 生成提示音

```bash
pip install google-cloud-texttospeech
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json   # 不要入库
python tools/gen_prompts.py --lang all --out audio/
python tools/check_lead_time.py --audio audio/ --config config/config.toml
```

语言：`cmn`（普通话，cmn-CN）、`yue`（粤语，yue-HK）、`en`（英语）。也可以先 `--backend espeak` 生成临时版本。

### 5.4 Pico

```bash
pip install mpremote
mpremote cp pico/*.py :                  # 拷到 Pico 根目录，重启后自动运行 main.py
```

引脚表在 `pico/config.py`。接线前看第 2 节「下单 / 装机前要核对」。

### 5.5 按键

### 5.6 手机定位

手机开热点，Pi 连上。手机浏览器打开 `https://<Pi 的 IP>:8443/phone?token=<CANE_PHONE_TOKEN>`，接受自签证书，允许定位。诊断网页默认只在 Pi 本机可看，要在实验网络里看需在配置 `web.diag_allow` 里加网段。
