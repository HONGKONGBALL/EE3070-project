## 修改后的提醒逻辑

保留原有 SegFormer-B0 和地面任务，在语义线程增加一次 MobileCLIP2-S0 场景复核。只运行一个固定关注区域、一个图像编码过程；没有给每种错误场景增加独立模型或备用算法。

复核使用固定英文文本向量区分楼梯、平地、鞋子/地垫等物件与其他背景。模型仍是冻结权重，文本原型和决策间隔属于开发集上的校准，不是独立测试通过证明。

- 场景楼梯分数与非楼梯分数之差至少 0.01：可补充语义分割漏掉的楼梯提醒。
- 已有楼梯分割区域在场景判断不确定时保留；差值低于 -0.03 的强非楼梯背景将其否决。
- 提醒继续需要两次不同帧的观察，沿用去重、冷却和唯一语音队列。
- 分数是余弦相似度，不是正确率，不将多个模型的分数直接加权。
- 新生成的虚线区域是分类观察区域，**不是精确物体框或台阶边界**。已有分割区域仍可显示实线外接框。
- **只播 `Possible stairs ahead.`** 上下方向的文本分数只用于研究/楼梯存在性复核，不会生成 up/down 语音。

主要文件：`pi/cane/vision/stair_context.py`、`ground.py`、`v2.py`；固定文本在 `config/stair-context-prompts.json`。运行文件为 `models/v2/stairs-context`，配置位于 `[semantic] stair_context_directory`。
