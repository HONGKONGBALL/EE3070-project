## 环境与配置

- Pi 5 / 8 GB，aarch64 Debian 13.7，Python 3.13.5；`gp7_3070@192.168.1.99`。
- 项目 `~/EE3070-project/`，虚拟环境 `.venv`；系统 OpenCV/NumPy，NCNN `1.0.20261020`。
- Logitech C270：`/dev/v4l/by-id/usb-046d_0825_5A2EE4D0-video-index0`，真实 USB 摄像头。
- 640×480 YUYV，采集请求 15 FPS、两个驱动缓冲；单采集线程只发布最新帧。
- YOLO11n COCO NCNN，416 输入、1 CPU 线程、置信度 0.45；当前推理上限 8 FPS，降低持续负载。
- HyperX 实际枚举 **HyperX Cloud II Core Wireless**，专用 USB 接收器，默认 PipeWire 输出。
- Pi 监听 `127.0.0.1:8000`；SSH 转发后电脑预览 `http://127.0.0.1:8010/`。
- 已安装并启用 `smart-cane-camera.service` 用户会话服务；未保证无人登录时启动。

模型来源、SHA-256、许可证见 `camera-third-party.md` 与 `models/yolo11n/manifest.json`。
模型、WAV、截图、日志和虚拟环境不进入 Git。
