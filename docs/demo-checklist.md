# 单摄像头实验室演示清单

安装与启停见 `camera-sample.md`，实测状态见 `camera-validation.md`。
支持人、椅子、背包；手提包和行李箱共用 Bag 语音。

## 演示前

1. 使用稳定的 Pi 5 电源，插入 C270 与 HyperX USB 接收器，打开耳机。
2. 登录 Pi，检查 `systemctl --user status smart-cane-camera --no-pager`。
3. Windows 保持 SSH 转发，浏览器打开 `http://127.0.0.1:8010/`；Pi 自己预览用端口 8000。
4. 确认画面更新、状态正常；摆正摄像头，固定支架，记录高度与倾角。

## 三类演示

将人、椅子、背包逐一放到中央下方关注区域，每次保持至少 3 秒：

- 检查框和类别；橙色表示受支持的前方提醒候选。
- 连续识别后显示并播放 Person / Chair / Bag ahead 英语短语。
- 同一目标保持 20 秒，应避免持续重复播报。移除至少 2 秒再放回，且距上次同类提醒超过 8 秒，才允许新提示。
- 目标放到区域外仍可显示框，但不应产生前方提示。
- 纸箱、复杂桌腿等不属于保证支持的类别。

关闭网页不停止服务。停止用 `systemctl --user stop smart-cane-camera`，
恢复用 `systemctl --user start smart-cane-camera`。

## 正式验收记录模板

每试次填一行，实际类别由人确认，不能使用模型输出代替标真：

| 试次 | 实际类别 | 位置/照明 | 放入/移除时间 | 框正确 | 2 秒内提醒 | 英语听感 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 待现场填写 | | | | | | | |

每类至少 10 次；另做区域外至少 10 次、空区域 5 分钟、持续目标 20 秒及真实相机拔插。
安装到拐杖后记录高度、角度和关注区域，慢速前进与轻微摆动时复测人/椅子各至少 5 次。
桌面演示成功不等于拐杖安装通过。

截图使用预览 Snapshot 链接；Pi 留档用 `POST /capture`。
日志在 `logs/camera-<run_id>.jsonl`；记录与试次对应，不提交个人画面到 Git。
