接线与使用说明

TFmini-S：白色 RX 接 GP8，绿色 TX 接 GP9，UART1 / 115200；红线接合适的 5V，黑线接地。前方超声波 TRIG GP2 / ECHO GP3，上方 TRIG GP4 / ECHO GP5。TRIG 按图经 SN74AHCT125N 升为 5V；Echo 经 2.2kΩ / 3.3kΩ 分压后进入 Pico，不能将 5V Echo 直接接到 GPIO。全部共地。

“临时运行测距程序”会暂停 Pico 当前程序，在 RAM 中读取两种测距模块，不写 main.py。只需本页连接一次；使用前断开旧 TFmini、超声波网页或 Thonny 的串口。“只接收”不发送命令，要求现有程序输出 TF_DATA / US_DATA 协议。

超声波依次触发，间隔至少 80 ms；激光帧在间隙读取。TFmini 时间及解析间隔是 Pico 处理串口帧的时间，超声波采集期间可能积压后集中解析，不能视为 TFmini 的真实采样间隔。三路并非同时测量。

TFmini 原始单位默认 cm；若传感器已经配置为 mm，请手选 mm。该选项只影响激光距离；改变单位会清空激光曲线，CSV 每条保留当时的单位。超声波按 343 m/s 换算，未做温度补偿。
